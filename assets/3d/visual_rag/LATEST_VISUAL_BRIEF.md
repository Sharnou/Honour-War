# Honour War — HD 3D Anime-Isometric MMORPG Visual RAG Brief

Source: repository Screenshot/ folder.

## Locked target identity

HD 3D anime-inspired medieval/fantasy MMORPG/ARPG.

The visual game is 3D, not a flat or placeholder presentation. Every completed visual development cycle regenerates the visual brief from the locked references, refreshes the 3D production assets and validates the result in the real Unreal runtime.

## Gameplay/camera identity

The gameplay interaction remains a Ragnarok Online-inspired desktop MMORPG pattern:
- left-click ground = click-to-move;
- left-click monster = select target and move into attack range;
- right-mouse drag = perspective/isometric camera orbit;
- mouse wheel = bounded zoom;
- W/A/S/D = secondary direct movement;
- 1–8 = gameplay skills.

The camera is a perspective, elevated isometric-style camera, defaulting around a -50° pitch and 45° yaw, with complete hero framing during normal play.

## Required 3D art

- expressive anime-inspired full-body heroes with visible faces, hair, hands, legs and feet;
- class-specific layered armor/clothing and weapons;
- Tier 1–5 visual progression and distinct Tier 5 silhouettes;
- pets and monsters with readable silhouettes and hit reactions;
- dense medieval towns, fields, mountains, rivers, ruins, snow regions and dungeons;
- detailed terrain, roads, vegetation, props and landmarks;
- PBR material variation;
- bright daylight and strong contact shading;
- readable attack, hit, projectile and skill VFX;
- compact MMORPG HUD.

## Pipeline

Visual RAG → gap register → regenerated visual brief → Neural4D or Blender → Substance 3D Painter → FBX/OBJ → Unreal Engine 5.8 → runtime validation → real EXE screenshot → reference comparison.

## Rejected

Godot, GLB, GLTF, Meshy, futuristic/modern/scifi machinery, robots, transformers, factories, space presentation, empty template maps and primitive-only final assets.

## Cycle rule

Visual cycles are on-demand development work. The contract preserves the visual target across each cycle but does not re-enable the retired unattended daily-upgrade system.
