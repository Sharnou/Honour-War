# Honour War 3D Characters

Place production character scenes here as `.glb`, `.gltf`, or `.tscn`.

Each class should eventually provide a complete adult fantasy character with skeleton and animation clips:
Idle, Walk, Run, Attack, Critical, Cast, Skill, Hit, Stun, Knockback, Death, Victory, Teleport.

Recommended source quality: high-detail model with 2K/4K textures and normal/roughness/metallic maps where appropriate.
