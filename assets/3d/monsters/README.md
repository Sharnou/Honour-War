# Honour War 3D Monsters

Production monster and MVP scenes belong here as `.glb`/`.gltf` assets.

Required families include Poring, Goblin, Wolf, Skeleton, Zombie, Orc, Mantis, Golem, Evil Druid and Dragon, plus every MVP definition.

MVPs should include unique silhouettes, attack phases, telegraphs, hit/stagger/death animation, and signature VFX hooks.
