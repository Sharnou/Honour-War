# Honour War 3D Maps

Production world scenes belong here as `.glb`, `.gltf`, or inherited Godot scenes.

Target environments: Prontera, Payon, Geffen, Morroc, Izlude, forests, caves, tower floors, ruins, deserts, snow fields, end-game zones and future world-event maps.

Use modular environment pieces, collision meshes, navigation data and LOD-ready scenery so high quality and high FPS can coexist.
