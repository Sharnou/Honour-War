# Honour War — HD Anime-Inspired Isometric Style Guide

This is the locked visual style for all Honour War development cycles.

## Character art

Use original anime-inspired fantasy proportions and presentation:
- readable expressive eyes and faces;
- stylized hair shapes with strand grouping;
- clean silhouette separation;
- layered medieval clothing and armor;
- distinct class weapons and accessories;
- visually strong Tier 5 Transcendence equipment;
- readable hands, legs and feet.

Avoid photorealistic faces, generic humanoid mannequins, bare primitive blocks as final character art, or modern/futuristic styling.

## World art

Use a rich isometric MMORPG composition:
- dense medieval streets;
- stone and timber architecture;
- layered roof silhouettes;
- banners, shops, market stalls, carts and lived-in props;
- grass, flowers, bushes, trees and rocks;
- rivers, bridges, mountains, ruins, snow fields and dungeons;
- strong landmarks that make each map visually identifiable.

## Surface treatment

The anime-inspired look is carried by stylized shapes plus detailed PBR surfaces:
skin, cloth, leather, wood, stone, metal, crystal and magic. Surface response must remain readable in bright daylight.

## Camera

Perspective/isometric-style third-person view:
- default pitch around -48°;
- pitch limits -62° to -28°;
- smooth horizontal mouse orbit;
- smooth wheel zoom;
- full hero visible during ordinary gameplay.

## Lighting and VFX

Bright fantasy daylight with contact shadows and atmospheric depth. Class VFX use stylized readable shapes, controlled glow and clear impact moments without obscuring the battlefield.

## UI

Compact MMORPG UI inspired by the locked repository screenshots: portrait/profile, RPG navigation, minimap, quests, chat and utility controls. No strategy command console or center-bottom eight-slot skill strip.

## Source order

Visual RAG/reference analysis → visual specification → Neural4D/Blender → Substance 3D Painter → FBX/OBJ → Unreal Engine 5.8 → real runtime frame.

This style guide applies to every development visual cycle.
