# Daily Honour War Upgrade — Social UI / Character Management

This checkpoint makes the following presentation rules part of the playable HD build:

- Character Status and Equipment are presented in one combined window, including stat-point allocation.
- A player's real character name is the map/dungeon nameplate shown to other players, replacing generic class labels such as Swordsman.
- The owner's own character name is hidden from the owner's view.
- Player class and level are not floating over the player's character.
- HP/SP bars are restricted to enemy, party-member and PvP target presentations.
- Right-clicking another player opens the player context and provides EQUIP.
- ESC provides exactly Create New Character, Switch Characters and Options.
- Create New Character accepts the real character name and class.
- Switch Characters uses the existing save system.
- The permanent visual-quality contract remains authoritative for future Daily Honour War Upgrades.

CI/build verification is required before this checkpoint is considered release-ready.
