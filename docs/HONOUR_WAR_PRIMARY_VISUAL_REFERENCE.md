## Unreal implementation rules

- Runtime engine: Unreal Engine 5.8.
- Visual workflow: Visual RAG → Neural4D/Blender → Substance 3D Painter → FBX/OBJ → Unreal.
- Godot is rejected permanently.
- GLB/GLTF are rejected for daily updates/runtime intake.
- Meshy is rejected.

## Required visual result

The game must contain complete medieval/fantasy spaces rather than empty planes; full-body characters rather than cropped/simple stand-ins; distinct class equipment; readable pets/monsters; layered roads/buildings/vegetation/props; strong daylight and contact shading; and readable attacks/hits/skills.

The player HUD must include status bars, target status, minimap, chat and the centered 8-slot COMBAT SKILLS bar. The old development command toolbar is not part of the player-facing design.

## Acceptance

Passing code/build tests alone does not establish the visual target. A real Unreal runtime screenshot is required and must be visually inspected against both locked anchors.
