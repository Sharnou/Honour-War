# Honour War — Sharnou Engine Production Art Library

This folder is the native Sharnou Engine destination for the production art library.

## Approved source path

Visual RAG → Neural4D / Blender → Substance 3D Painter → FBX/OBJ + texture maps → Sharnou Engine.

GLB and GLTF are permanently rejected from Honour War runtime intake. Meshy is permanently rejected.

## Quality target

The two locked visual anchors are:

- Screenshot/ChatGPT Image Sep 16, 2026, 12_22_47 AM.png
- Screenshot/image_a4469f29.jpg

The game must retain a complete full-body hero, visible face/legs/feet, distinct class silhouette, layered equipment, detailed terrain, medieval architecture, vegetation, props, readable combat VFX and a polished MMORPG HUD.

## Folder taxonomy

- Characters
- Monsters
- Pets
- Equipment
- Weapons
- Maps
- Props
- Effects
- UI

Each production asset should have an ID, source-file record, scale, collision notes, material slots, animation list and LOD plan.
